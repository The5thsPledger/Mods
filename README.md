# Pasta de mods de Balatro
1. Siga o passo a passo do [lovely](https://github.com/ethangreen-dev/lovely-injector?tab=readme-ov-file#manual-installation)
2. Localize sua pasta Mods
3. Na pasta anterior (Balatro/) exclua a pasta Mods, abra o terminal na pasta atual e execute
```bash
git clone --recurse-submodules https://github.com/The5thsPledger/Mods.git
```
